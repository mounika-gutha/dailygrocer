# FreshCart Grocery Store

A simple grocery shopping website built for learning frontend, backend, JSON data, Linux, VS Code and Git.

## Technologies

- HTML
- CSS
- JavaScript
- Python
- Flask
- JSON

## Products

- Apple - ₹120 / 1 kg
- Banana - ₹60 / 1 dozen
- Orange - ₹100 / 1 kg
- Milk - ₹60 / 1 litre
- Bread - ₹45 / 1 pack
- Eggs - ₹90 / 12 eggs
